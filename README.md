# CampusT 前端 Demo v0.5

## 链上摄影 NFT：品牌与学生测试（v0.5）

入口：侧栏「链上 NFT」（`#nft`），品牌工作台「发放 NFT」（`#nft?role=brand`）。真实 Monad 测试网 ERC-721；品牌与学生都通过自己的浏览器钱包签署交易。页面不读取私钥，不内置公共部署账户。

1. 准备 A、B 两个钱包，分别充入足够支付 Gas 的测试 MON。A 为品牌，B 为学生；切换页面角色不会切换钱包账户。
2. A 进入品牌端，设置发行上限（默认 100，范围 1–10000），部署「CampusT LUMA Photo Walk」系列。上限部署后固定，无需另充 NFT 奖励池本金。
3. A 填写 B 的钱包地址，核实参与资格后点击「授权 NFT 领取」，等待链上确认。品牌可查询某地址的授权/领取/持有状态，可撤销资格、暂停或恢复领取。
4. 复制页面生成的 `#nft?collection=0x…` 链接，用 B 打开并连接钱包。B 点击「免费领取 NFT」，支付测试网 Gas。每个地址每个系列只能领取一次，转出也不重置领取资格。
5. 领取后查看链上图片和编号，点击「穿戴光迹 NFT 头像框」。个人名片、社区头像及「我的装扮 → 链上藏品」同步显示。NFT 允许 ERC-721 转赠，转出后刷新会移除原持有者穿戴资格；持有藏品不是本人到场证明。

NFT 与 MON 奖励池是独立合约，领取 MON 的授权不会自动授权 NFT。学生填 NFT 合约地址，不填钱包或 MON 奖励池地址。每次部署产生独立系列；网站核验其运行时代码与当前版本一致，品牌身份须核对部署者地址。

图片 SVG、介绍、编号与属性由合约生成 `data:` URI，全部在链上，无需 IPFS 或图床。系列为固定摄影主题；每个 NFT 有独立 Token ID。采用固定 OpenZeppelin 5.4.0 的 ERC721Enumerable，支持从当前钱包枚举一枚所持藏品进行展示；多枚同系列 NFT 解锁同一款头像框。部分钱包未必自动展示测试网或内嵌 SVG 藏品，可在本站或区块浏览器查看。

装扮选择与最近合约地址保存在本机；持有资格从链上读取，切换账户或网络立即失效并重新验证。可通过领取链接在新设备导入同一系列。前台每 30 秒刷新（输入表单时不打断），状态超过 60 秒未核实时不展示链上穿戴标记。交易哈希保存到本地，刷新可恢复已提交的部署交易。首次真实部署及交易仍需用户钱包逐笔确认。

- `contracts/CampusPhotoNFT.sol`：测试网专用 NFT 合约，完整 ERC-721 转移、所有者授权、领取上限、防重复及全链上元数据。
- `npm run build:nft`：编译 ABI、部署代码和运行时代码；使用 Solidity 0.8.30、Paris EVM、optimizer 200。
- `npm run test:nft`：本地 EVM 验证权限、授权撤销、暂停恢复、领取去重、限量、元数据、转移、接收合约回调重入和拒绝主网部署。
- `scripts/test-nft-ui.mjs`：独立本地链 + Edge CDP 9229 验证双角色全流程、拒绝签名、错误地址/网络、切换账户、转出失效、刷新恢复、390px 手机布局。需本地站点 4173；测试 RPC 为 8548，仅测试脚本注入，生产页始终使用 Monad Testnet RPC。

已完成本地合约与浏览器双端测试；这些测试不消耗用户测试币，也不冒充已在真实 Monad 测试网完成部署。

## 默认免费装扮（v0.4.1）

所有新老用户在打开页面时自动拥有 6 件装扮：薄荷心情、晴空来信、樱花笔记头像框，以及晨光校园、方格手账、湖畔午后主页背景。在「我的 → 我的装扮」直接切换，无需钱包、购买或领取，也不产生积分收支或兑换订单。

使用稳定 ID 去重补发，保留现有装扮、穿戴、活动奖励和积分。免费装扮与活动/兑换装扮分组展示，商城不出售免费款。头像框与主页背景可独立搭配，选择仍保存在当前浏览器。

## Monad 测试网奖励池

`#monad` 为真实钱包及测试 MON 奖励页。此功能使用原生测试 MON，不是平台积分或 ERC-20。链 ID 固定 10143；所有交易均由浏览器钱包签署，代码不读取或保存私钥。

1. 品牌连接持有测试币的钱包，在「品牌工作台 → 管理奖励池」部署并充值。每人固定 0.001 测试 MON；初始预算默认 0.01，可修改，另需预留 Gas。
2. 品牌核实参与情况，填写学生钱包地址并授权。由于现场记录仍是 localStorage 演示，合约不把这些记录当成可信资格。
3. 复制奖励页提供的 `#monad?pool=0x…` 链接给学生。学生使用自己的钱包打开链接，支付测试网 Gas，自行领取。
4. 合约负责领取资格、每地址一次、资金不足拒绝发放。品牌可以追加预算、撤销未领取资格、永久关闭奖励池并取回余款。

在网页中实际部署前，没有预设公共奖励池地址。不同浏览器需通过分享链接或导入地址选择同一个池。每次新部署都是一个独立奖励池，不共享领取记录。

- `contracts/CampusRewardPool.sol`：仅测试网部署的活动奖励合约，原生 MON 定额发放，调用前更新领取状态并设重入锁。
- `scripts/build-chain.mjs`：使用固定 Solidity 编译器、Paris EVM 和优化参数编译；生成完整 ABI、部署代码与运行时代码，并打包 ethers。
- `scripts/test-chain.mjs`：本地合约测试，不消耗真实账户资金。
- `scripts/test-chain-ui.mjs`：使用独立浏览器和临时本地链的界面测试，不连接真实钱包。
- `dist/monad.js`：EIP-6963 / 注入式钱包选择、网络切换、合约代码校验、交易确认与查询。

测试网合约原型尚未经过独立审计。学生身份、签到真实性、资格审核和跨设备数据同步仍需正式服务端；请勿用于主网资金。

校园活动、兴趣社区、积分商城与个人名片的响应式交互原型。纯 HTML/CSS/JavaScript，无需安装依赖，也可直接打开 dist/index.html。

## 体验路径

- 发现活动：按校园、类别、关键词筛选，并按热度或时间排序。
- 活动详情：开启体验钱包 → 报名 → 模拟签到 → 领取奖励。
- 校园社区：发布动态、点赞、评论、加入兴趣圈；申请组队或发布招募。个人名片展示共同兴趣，支持保存交流申请、屏蔽与举报记录。
- 奖励商城：兑换品牌福利或装扮。待核销订单可取消退款，核销后不能重复领取。数字装扮每款限兑一次，不支持取消。
- 我的：积分账本、活动进度、兑换订单、装扮穿戴与 NFT 活动徽章。头像框同步出现在名片、动态和评论，背景装扮用于自己的主页。
- 品牌工作台：创建本地活动，活动会同步显示在活动广场。

人物、活动、品牌、库存为虚构演示数据。签到、积分、兑换核销、体验账号和旧版活动徽章为本地模拟；`#monad` 与 `#nft` 使用真实钱包和测试网交易。申请交流、组队和举报仅在本机保存，不向任何人发送消息。演示进度通过 localStorage 保存在当前浏览器，保留旧版活动进度；直接打开文件与 HTTP 打开的存储空间可能不同。

首次使用新版赠送 180 体验积分。每场完成的活动领取 100 积分，旧版已完成活动会补记一次。积分不可转让、不可提现，本 Demo 不设到期。发帖、评论和点赞不奖励积分。新建活动日期固定为 12 月 12 日，奖励固定 100 积分，可选纪念 NFT。
