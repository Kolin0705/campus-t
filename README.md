# CampusT · 连接校园，让热爱发生

CampusT 是一个面向学生和品牌方的校园活动与社区平台原型。品牌通过校园活动与学生建立联系，学生通过参与活动获得积分、装扮和链上收藏，并在社区中认识同好、寻找合作伙伴。

平台串联活动发现、现场扫码、奖励兑换、社区交流与个人展示，并接入 **Monad 测试网**：品牌部署奖励合约并授权，学生使用自己的钱包领取测试 MON 和 ERC-721 NFT。

**[在线体验](https://campus-t-kolin-demo.lacyalbatross5.chatgpt.site)** · **[GitHub 仓库](https://github.com/Kolin0705/campus-t)**

> 当前版本为 v0.5 Demo。活动、品牌和人物为演示设定；积分、商城、签到和社区互动保存在当前浏览器。MON 奖励与摄影 NFT 使用真实测试网交易，所有交易均需钱包确认。

## 主要功能

| 功能 | 使用方式 | 当前实现 |
| --- | --- | --- |
| 校园活动 | 按校园、类别或关键词发现活动，查看详情并报名 | 本地演示 |
| 现场扫一扫 | 使用相机、相册或活动链接完成签到与签退 | 本地记录，二维码在设备上解析 |
| 校园社区 | 发布动态、点赞评论、加入兴趣圈、发布组队招募或申请合作 | 本地演示，申请不会发送给真实用户 |
| 积分与奖励商城 | 参与活动赚积分，兑换品牌福利、体验席位及装扮，查看订单与积分明细 | 积分、库存、订单和核销均为模拟 |
| 免费装扮 | 默认拥有 3 款头像框和 3 款主页背景，可自由搭配 | 无需购买、积分或钱包 |
| 活动限定装扮 | 完成摄影活动解锁头像框，在名片、动态和评论中展示 | 本地活动奖励 |
| MON 奖励池 | 品牌部署、充值并授权，学生自行领取每人 0.001 测试 MON | Monad 测试网合约 |

| 品牌工作台 | 创建演示活动、下载现场二维码物料、管理链上奖励 | 活动为本地演示，奖励管理为测试网交易 |

## 学生使用指南

### 1. 发现与参加活动

1. 在「发现活动」选择校园，浏览或搜索感兴趣的活动。
2. 打开活动详情，按提示开启本地体验账号并报名。
3. 到达现场后进入「扫一扫」，扫描参与码完成签到。
4. 活动结束后扫描签退码，领取对应的本地积分与装扮奖励。

摄影活动「LUMA 光迹 · 把校园拍成明信片」已配好演示参与码和签退码，可在「品牌工作台 → 现场物料」体验完整流程。签到和签退应在同一浏览器完成，重复签退不会重复发奖。相机不可用时，可从相册识别二维码或粘贴活动链接。

### 2. 使用积分与装扮

- 首次体验赠送 180 积分，完成活动可获得 100 积分。进入「奖励商城」兑换内容，在「我的」查看订单和积分账本。
- 品牌福利订单支持演示核销；待核销订单可取消并退回积分。数字装扮每款限兑一次。
- 在「我的 → 我的装扮」选择头像框或主页背景，头像框同步展示在个人名片、动态与评论中。
- 默认免费头像框：**薄荷心情、晴空来信、樱花笔记**。
- 默认免费主页背景：**晨光校园、方格手账、湖畔午后**。

积分不可提现或转让，演示奖品不能兑换为真实品牌商品。

### 3. 交流与寻找合作

进入「校园社区」，按兴趣浏览动态、加入圈子、发布内容，或通过组队招募寻找摄影、设计、开发等方向的合作伙伴。个人名片可编辑兴趣，装扮帮助表达个人风格。

目前社区人物与内容为演示数据，发布、评论、申请交流和组队进度仅保存在本机，尚未提供真实多人聊天和跨用户同步。

### 4. 领取测试 MON

1. 准备兼容的浏览器钱包，切换至 **Monad Testnet**，确保学生钱包有测试 MON 支付 Gas。手机可使用钱包应用的内置浏览器。
2. 将自己的钱包地址交给品牌，等待品牌核实参与情况并授权。
3. 打开品牌分享的领取链接，或进入 [MON 奖励页](https://campus-t-kolin-demo.lacyalbatross5.chatgpt.site/#monad)，导入品牌提供的**奖励池合约地址**。
4. 连接学生钱包，刷新链上状态。显示已授权且奖励池余额充足后，点击领取并在钱包中确认。
5. 等待链上确认，每个钱包在同一个奖励池中只能领取一次，金额固定为 **0.001 测试 MON**。

### 5. 领取与穿戴 NFT

1. 将学生钱包地址交给品牌，由品牌在 **NFT 品牌端单独授权**。
2. 打开品牌分享的 NFT 领取链接，或进入 [NFT 学生端](https://campus-t-kolin-demo.lacyalbatross5.chatgpt.site/#nft)，导入**NFT 合约地址**。
3. 连接学生钱包，刷新链上状态，点击「免费领取 NFT」并确认交易。
4. 领取成功后查看链上图片与 Token ID，点击「穿戴光迹 NFT 头像框」，也可在「我的 → 我的装扮 → 链上藏品」查看。

NFT 免费铸造，但学生仍需支付测试网 Gas。每个钱包每个系列只能领取一次，转出后不能再次领取。穿戴资格依据当前钱包的链上持有情况核实，转出后刷新会取消原持有者的链上穿戴资格。

## 品牌使用指南

### 1. 创建校园活动

进入「品牌工作台」，填写活动名称、介绍、校园、类别、人数上限等信息，发布后可在当前浏览器的活动广场查看。

当前创建功能用于演示：活动不会同步给其他设备或真实学生，新建活动使用固定演示日期。发布本地活动不会自动部署 MON 奖励池或 NFT 合约。

### 2. 准备现场物料

进入「品牌工作台 → 现场物料」，获取预设 LUMA 摄影活动的参与码、签退码、可打印海报和透明头像框素材。

- 活动开始：展示参与码，学生扫码报名并签到。
- 活动结束：展示签退码，学生完成签退后获得本地奖励。

当前二维码是静态演示码，不提供真实到场核验。发放链上奖励前，品牌需要自行核实参与资格。

### 3. 发放测试 MON

1. 连接品牌钱包，准备奖励预算以及部署、授权等操作所需的测试网 Gas。
2. 进入「品牌工作台 → 管理奖励池」，设置首次预算，部署并充值奖励池。
3. 默认预算为 **0.01 测试 MON**，可供 10 人各领取 0.001；该预算不包含部署和管理交易的 Gas。
4. 填写已核实学生的钱包地址，授权其自行领取，单次最多 100 个地址。
5. 将生成的领取链接发给学生。品牌可以追加预算、撤销未领取资格，并查看奖励池余额与领取人数。
6. 活动结束后可关闭奖励池，再取回剩余预算。**关闭是永久的；如需重新发放，应创建新的奖励池。**

奖励由学生主动领取，品牌授权本身不会直接向学生转账。

### 4. 发放摄影 NFT

1. 进入「品牌工作台 → 发放 NFT」或 [NFT 品牌端](https://campus-t-kolin-demo.lacyalbatross5.chatgpt.site/#nft?role=brand)。
2. 连接品牌钱包，设置发行上限并部署「CampusT LUMA Photo Walk」系列。默认 100 枚，范围 1–10000，部署后上限固定。
3. 输入已核实的学生钱包地址，勾选资格确认并点击「授权 NFT 领取」。
4. 等待链上确认，再复制 NFT 领取链接发给学生。
5. 使用地址查询功能核对学生的授权、领取和当前持有状态。品牌可撤销未领取资格，也可暂停、恢复领取。

NFT 发放无需预存奖励本金，品牌仍需支付部署与授权交易的 Gas。只有部署该系列的钱包可以管理，页面切换至「品牌端」不会自动获得管理权限。撤销资格不会收回已经铸造的 NFT。

当前 NFT 为固定摄影主题，不支持通过表单上传任意图案。图案 SVG、名称、介绍与属性由合约生成，每枚 NFT 有独立编号。NFT 支持 ERC-721 转赠，持有藏品不等于本人参加过活动。

## 双角色测试与常见问题

建议使用 **A 钱包作为品牌、B 钱包作为学生**，分别准备测试 MON，依次完成「A 部署 → A 授权 B → B 领取 → B 穿戴」。页面上的角色切换只改变视图，实际账户需在钱包中切换。

| 问题 | 处理方法 |
| --- | --- |
| 导入栏应该填什么？ | MON 页面填奖励池合约地址，NFT 页面填 NFT 合约地址，都不是个人钱包地址。优先使用品牌分享的领取链接。 |
| 已领取 MON，但 NFT 显示未授权？ | 两者使用不同合约，品牌需要分别授权。 |
| 钱包无法确认领取，余额为 0？ | 学生钱包必须先有测试 MON 支付 Gas。根据钱包显示的最大费用准备余额，不能用尚未到账的奖励支付当前交易费用。 |
| 0.001 MON 奖励是否足够支付 NFT Gas？ | 不保证。奖励金额与 Gas 独立，费用随交易及网络变化，以钱包实时估算为准。 |
| 品牌端无法管理合约？ | 检查是否连接了部署该合约的钱包，以及是否导入了正确的合约地址。 |
| 刷新或换设备后看不到 NFT？ | 重新连接持有 NFT 的钱包，通过品牌链接导入同一个系列，再刷新链上状态。穿戴选择保存在本机。 |
| 钱包里没有自动显示 NFT 图片？ | 可在本站查看合约返回的图片与编号，或通过区块浏览器链接核对持有情况。 |
| 交易仍显示等待确认？ | 先刷新链上状态或查看交易链接，确认结果后再继续，避免重复发送。 |

链上功能仅面向 Monad Testnet（Chain ID **10143**）。测试 MON 与网站积分是不同的奖励。代码不读取或保存钱包私钥，交易通过用户钱包签署。

## 技术结构与本地运行

前端使用原生 HTML、CSS 和 JavaScript，无需前端构建步骤。钱包交互使用 ethers，NFT 合约基于 OpenZeppelin ERC721Enumerable，编译使用 Solidity 0.8.30、Paris EVM 和 optimizer 200。

```text
campus-t/
├── dist/                  # 可直接托管的网页、样式、图片及浏览器脚本
│   ├── contracts/         # 浏览器使用的 ABI、部署字节码和合约源码
│   └── vendor/            # ethers、二维码解析库及许可证
├── contracts/             # MON 奖励池与摄影 NFT 的 Solidity 源码
├── scripts/               # 合约编译、二维码生成和测试脚本
├── .openai/hosting.json    # 当前 Sites 托管配置
├── server.mjs             # 本机静态预览服务
└── package.json
```

安装 Node.js 后，在项目根目录启动预览：

```bash
npm run dev
```

打开 [本地预览](http://localhost:4173)。静态预览不需要先安装开发依赖；运行检查、生成素材或编译合约时，先执行 `npm ci`。

| 命令 | 用途 |
| --- | --- |
| `npm run check` | JavaScript 语法检查与二维码解码检查 |
| `npm run build:chain` | 编译 MON 奖励池合约并生成前端产物 |
| `npm run build:nft` | 编译摄影 NFT 合约并生成前端产物 |
| `npm run test:contract` | 在本地 EVM 验证 MON 奖励池 |
| `npm run test:nft` | 在本地 EVM 验证 NFT 权限、领取、限量、元数据及转移 |
| `npm run generate:qr` | 生成预设摄影活动的二维码物料 |

`scripts/test-chain-ui.mjs` 和 `scripts/test-nft-ui.mjs` 为开发阶段的浏览器集成测试，使用独立 Edge 调试实例及临时本地链，不连接用户真实钱包。脚本包含本机路径和端口配置，迁移环境时需调整；NFT 页面测试需启动本地站点 4173 与 Edge CDP 9229，测试 RPC 使用 8548。

## 当前范围

已验证本地合约与双角色浏览器流程，包括授权撤销、重复领取拦截、暂停恢复、NFT 转移后穿戴失效、钱包切换、交易恢复，以及桌面和 390px 移动端布局。相机流程使用模拟设备验证，尚未完成真实手机镜头实测。自动化测试使用本地 EVM，公网测试网交易由体验者使用钱包确认。

项目尚未接入真实校园认证、服务端活动与订单、多人社区同步、可信现场核验或正式品牌奖品履约。测试网合约尚未经过独立审计，目前用于产品演示和测试网体验。
