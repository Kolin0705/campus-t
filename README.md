# CampusT 前端 Demo v0.2

校园活动、兴趣社区、积分商城与个人名片的响应式交互原型。纯 HTML/CSS/JavaScript，无需安装依赖，也可直接打开 dist/index.html。

## 本地运行

```powershell
cd E:\campusT\campus-demo
npm run dev
```

打开 http://localhost:4173 。语法检查：`npm run check`。

## 体验路径

- 发现活动：按校园、类别、关键词筛选，并按热度或时间排序。
- 活动详情：开启体验钱包 → 报名 → 模拟签到 → 领取奖励。
- 校园社区：发布动态、点赞、评论、加入兴趣圈；申请组队或发布招募。个人名片展示共同兴趣，支持保存交流申请、屏蔽与举报记录。
- 奖励商城：兑换品牌福利或装扮。待核销订单可取消退款，核销后不能重复领取。数字装扮每款限兑一次，不支持取消。
- 我的：积分账本、活动进度、兑换订单、装扮穿戴与 NFT 活动徽章。头像框同步出现在名片、动态和评论，背景装扮用于自己的主页。
- 品牌工作台：创建本地活动，活动会同步显示在活动广场。

人物、活动、品牌、库存和奖励均为虚构演示数据。钱包、签到、兑换核销与 NFT 为本地模拟，无真实资金、签名或链上交易。申请交流、组队和举报仅在本机保存，不向任何人发送消息。进度通过 localStorage 保存在当前浏览器，保留旧版活动进度；直接打开文件与 HTTP 打开的存储空间可能不同。

首次使用新版赠送 180 体验积分。每场完成的活动领取 100 积分，旧版已完成活动会补记一次。积分不可转让、不可提现，本 Demo 不设到期。发帖、评论和点赞不奖励积分。新建活动日期固定为 12 月 12 日，奖励固定 100 积分，可选纪念 NFT。

## 文件

- `dist/index.html`：页面框架和弹窗。
- `dist/style.css`：响应式样式与 CSS 海报。
- `dist/app.js`：活动数据、视图、交互及本地持久化。
- `dist/community.js`、`dist/community.css`：社区、个人主页、积分账本与奖励商城。
- `server.mjs`：仅监听本机的静态预览服务。
